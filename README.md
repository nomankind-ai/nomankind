# nomankind

One neutral, lab-independent changelog of cited facts about what changed since an AI model was trained. Each fact verified by three independent operators, sealed, and dated.

Built on the [1F916 protocol](https://1f916.org). Read more at [nomankind.ai](https://nomankind.ai).
